# Changelog

All notable changes to this workflow are recorded here. The version identifies the *workflow*, so
an engagement can state which version it was delivered with.

## [0.1.0] - 2026-08-24

### Added

- Initial release, split out of `data-project-1`.
- Skills: `md-dashboard-diagnostic`, `md-dashboard-redesign`, `md-table-spec-builder`,
  `ant-build-dashboard`, `md-skill-optimizer`.
- Prompts wrapping the redesign workflow, with and without pre-selected dashboard type.
- Design references for the four dashboard types.
- `dashboards/PNL_Dashboard/` as a worked example of the diagnostic and redesign steps.
- `handoff/` for bundles exported to the delivery kit.
